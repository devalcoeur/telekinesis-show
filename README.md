# TELEKINESIS SHOW — финальная версия сайта

Одностраничный сайт Christian Devalcœur / «Телекинез шоу» с главной анимацией, тремя видео и шестью реакциями зрителей.

Публикация через GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

Файлы сайта находятся в корне репозитория. Главная страница — `index.html`.

Третий телевизионный сюжет: `TV_BROADCAST_WEB.mp4` (45 секунд). Превью извлечено из оригинального сюжета. Другие видео и фон находятся в соответствующих папках. Сохраняйте структуру каталогов.

Обновление через GitHub Desktop: скопируйте обновлённые файлы в локальную папку `telekinesis-show`, затем Commit to main → Push origin. GitHub Pages автоматически обновит сайт.
