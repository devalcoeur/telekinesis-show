# TELEKINESIS SHOW — официальный сайт

Статический сайт на основе утверждённой версии V11. Для публикации на GitHub Pages нужен `index.html` в корне ветки `main`.

## GitHub Pages

1. Создайте **public** репозиторий `telekinesis-show` в своём аккаунте GitHub (или используйте иное выбранное имя).
2. Загрузите **всё содержимое этой папки** в корень репозитория (не саму папку). Проверьте, что `index.html` и `main-film-web.mp4` лежат в корне.
3. В репозитории перейдите в **Settings → Pages → Build and deployment**. В Source выберите **Deploy from a branch**, в Branch — `main` и `/ (root)`, затем сохраните.
4. Типичная ссылка: `https://devalcoeur.github.io/telekinesis-show/` (зависит от имени репозитория).

Важно: главный ролик оптимизирован специально для веб-публикации; исходный мастер-файл не менялся. Если `main-film-web.mp4` не загружен, первый основной видеоплеер не заработает.

Сайт содержит медиафайлы с персонами: перед публикацией убедитесь, что у вас есть права на публичное распространение материалов.
